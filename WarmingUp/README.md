# Atividades de MySQL — UPDATE, DELETE, GROUP BY e Funções de Agregação

Exercício prático de SQL usando uma tabela única (`vendas`) para praticar:

- `UPDATE` (com condições e cálculos)
- `DELETE`
- `GROUP BY` com funções de agregação (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- `HAVING`
- `ORDER BY`

## Arquivos

- `warming_up.sql` — script de criação da base `db_2_bim`, tabela `vendas` e carga inicial dos 100 registros.
- `respostas.sql` — respostas das 10 questões propostas no exercício.

## Como executar

```bash
mysql -u root -p < warming_up.sql
mysql -u root -p < respostas.sql
```

Todas as queries foram testadas em MySQL/MariaDB 10.11+ antes de serem publicadas.
