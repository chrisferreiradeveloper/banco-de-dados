
🗄️ Banco de Dados — Exercícios de SQL

Repositório com exercícios práticos de SQL desenvolvidos durante o curso, cobrindo desde consultas básicas até tópicos mais avançados como CTEs, JOINs e subconsultas com EXISTS.

📁 Estrutura do repositório
Pasta	Conteúdo
WarmingUp/	Exercícios de aquecimento — criação do banco de vendas e inserções iniciais
BetweenExistsIn/	Consultas com BETWEEN, IN, LIKE e EXISTS
CTES/	Consultas com Common Table Expressions (CTEs)
InnerJoin/	Exercícios de INNER JOIN
LeftJoin/	Exercícios de LEFT JOIN
FirstChallengeNight/	Desafios da primeira noite de prática
🛠️ Tecnologias
MySQL — banco de dados relacional utilizado em todos os exercícios
🎯 Objetivo

Praticar e consolidar conceitos de SQL como:

Filtros e intervalos (BETWEEN, IN, LIKE)
Subconsultas e verificação de existência (EXISTS)
Junções entre tabelas (INNER JOIN, LEFT JOIN)
Consultas estruturadas com CTEs (WITH)
Tratamento de valores nulos (COALESCE)
🚀 Como usar
Clone o repositório:
bash
   git clone https://github.com/chrisferreiradeveloper/banco-de-dados.git
Abra os arquivos .sql no MySQL Workbench (ou outra ferramenta de sua preferência).
Execute as consultas na ordem sugerida por cada pasta.
